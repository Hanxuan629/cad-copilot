Neuro-symbolic split

  • Perception (type / count / rough place) → LoRA-finetuned Qwen3-VL-2B
  • Geometry (exact coordinates) → least-squares snap to image ink, PNG-only
  • → measure each axis separately: edit-distance vs chamfer

Task 2 setup: pair each drawn curve to the target curve it represents
one real MRCAD trial · left = human-drawn CAD, right = target · same colour = a matched pair

What is line matching?

  • Input: a set of drawn curves + a set of target curves (same coordinate frame)
  • Output: for each drawn curve, which target it corresponds to (one-to-many allowed)
  • → a discrete correspondence problem — no coordinate generation needed

Task 2 — result

  • GT is built BY the geometric matcher, so it scores 1.00 by definition — a reference, not a perfect oracle (it can mis-pair a distorted stroke)
  • Zero-shot VLM reaches only 0.15 (text) / 0.11 (visual) of that reference
  • → even against a simple geometric labeller, the VLM is the wrong tool here

One consistent finding across every probe
Large pretrained VLM / text models are strong at perception and semantics but weak at precise geometry. Geometry is better served by small, geometry-native methods — least-squares refinement, geometric matching, a set-autoencoder. The win is putting each tool where it is strong.
